# AdmitBD

A Bangladesh university admissions tracking platform — built for students, by a student.

## Features

- 173+ universities tracked (public, private, international)
- Eligibility checker based on SSC & HSC GPA
- Admission deadline tracker
- AI-powered admission advisor (Groq Llama 3.3)
- Auto-scraper for admission circulars

## Tech Stack

- **Backend:** Flask (Python)
- **Database:** Supabase (PostgreSQL)
- **AI:** Groq API (llama-3.3-70b-versatile)
- **Scraping:** BeautifulSoup + pdfplumber
- **Hosting:** Vercel
